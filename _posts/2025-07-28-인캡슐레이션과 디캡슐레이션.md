c## 인캡슐레이션이란?

> **상위 계층에서 생성한 데이터를 하위 계층으로 내려보내면서, 계층별로 헤더를 덧붙이는 과정**  
> 즉, "포장"한다고 보면 됨.

---

## OSI 7계층 기반 인캡슐레이션 과정

![](UDP_encapsulation.svg.png)

| 계층 | 데이터 형태 | 역할 |
|------|-------------|------|
| 7계층 (Application) | Data | HTTP, FTP 등 사용자 요청 처리 |
| 6계층 (Presentation) | Data | 인코딩, 압축, 암호화 (거의 생략됨) |
| 5계층 (Session) | Data | 세션 유지, 연결 제어 (역시 실무선 생략되는 경우 많음) |
| 4계층 (Transport) | **Segment** | TCP/UDP 포트 정보, 신뢰성 보장 |
| 3계층 (Network) | **Packet** | IP 주소 기반 라우팅 |
| 2계층 (Data Link) | **Frame** | MAC 주소 기반 전달, 오류 검출 (FCS) |
| 1계층 (Physical) | Bit | 전기/광 신호로 물리적 전송 |

> 💡 데이터가 내려갈수록 헤더가 덧붙고, 수신 측에서는 반대로 **디캡슐레이션**(헤더 제거)을 수행한다
